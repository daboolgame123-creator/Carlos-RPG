# PLAY-08 — سجل الهدايا التي قدمها كارلوس

**تجربة محلية معزولة، غير مرتبطة بقصة كارلوس الأصلية.**

بعد شراء خبز من سلمى وتسليم رغيف لها، يستطيع اللاعب كتابة:
```text
buy salma-bread 2 2
give salma bread 1
gifts
handoff
```

يعرض الأمر `gifts` عدد الهدايا التي **سُلّمت فعلًا** وآخر 20 منها،
بحقول: المستلم، المورد، الكمية، زمن التسليم المنطقي. يعرض
`handoff` آخر خمس هدايا في `player_gifts`، منفصلة عن
`player_purchases`، دون إعادة حساب الشراء أو تغيير مخزون أحد.

## الحدود والضمانات

- القائمة تستند إلى أحداث `PlayerGiftDelivered` المقبولة والمتحقق منها،
  وليست نوايا أو محاولات رُفضت. تعاد قراءتها بعد الانتقال والحفظ وإعادة الفتح.
- تُرتّب الهدايا بترتيب تسجيل الحدث، بما في ذلك التسليمات المتعددة في نفس الثانية.
- لا تكشف سجل سلوك بقية الأشخاص، ثقتهم، أسباب القبول، احتياجاتهم، أرصدتهم،
  ملفاتهم الطبية أو الأحداث الخام. لا تستخدم صياغة تُوحي بالامتنان المفترض.
- `gifts` و`handoff` استعلامان للقراءة فقط؛ لا يقدّمان موردًا أو يقدمان الزمن.
- لا تغيير في Schema 33 أو Rules 43، ولا ترحيل، ولا إضافة حق دخول غير موثوق.
- P0 غير معتمد للإنتاج؛ المراجعة المستقلة مؤجلة؛ 03-A7c و03-A مفتوحتان.
- الفرع `main` وملفات القصة الأصلية لم تتغير.

## القبول

يشمل الاختبار: هوية اللاعب، العدد والحدود، رفض وتكرار الأوامر،
التسليم المتزامن، سلامة سجل الأحداث ضد التزوير، مراجعة التسليم
للراوي، إعادة فتح SQLite، وواجهتي CLI. لا يُعلن الإغلاق قبل نجاح
GitHub Actions الكامل على Python 3.10 و3.13 وعلى SHA الشيفرة النهائي.
