# PLAY-19 — تجربة رحلة متصلة في القرية

## تحليل قبل التنفيذ

مراحل PLAY-01–18 اختبرت البيع والهدية والطعام والحركة والحوار
والذاكرة بشكل منفصل. خطر المرحلة هو أن **الأنظمة الناجحة منفردة
قد تتعارض عند استخدام التسلسل نفسه** (مثلاً: تشتري ثم تهدي
ثم تأكل ثم يقرر NPC العمل ثم تسافر ثم تجمع الطعام ثم تستعيد الحفظ).

اخترنا رحلة اختبار ثابتة بأوامر اللاعب الحقيقية، بلا توليد حوار
خيالي ولا تغيير لقرارات الشخصيات. يُجري المحرك قرارات NPC أثناء
`wait` كما هي في الوضع العادي، وتبقى النتيجة حتمية وقابلة للإعادة.

## تسلسل التجربة

- القرية تضم كارلوس وسبعة NPC مستقلين موزعين بين الساحة والمخبز والغابة.
- يراقب كارلوس الساحة، ويسأل باسم عن مصدر طعام شاهده بالفعل؛
  تبقى الإجابة `hearsay` غير مؤكدة.
- يتحدث مع باسم، يشتري **3 أرغفة بـ6 قطع نحاس** من سلمى،
  ويهديها رغيفًا واحدًا ثم يأكل رغيفًا آخر.
- بعد `wait 1` تنطلق أحداث NPC المستقلة؛ تُحفظ المشاهدات
  الواقعية القريبة فقط.
- يسافر 40 ثانية إلى المخبز، ويشاهد المكان. يتحدث مع نورا
  فقط إذا بقيت موجودة فعلًا. يعود إلى الساحة خلال 40 ثانية،
  ثم يسافر 50 ثانية إلى الغابة.
- يبحث عن الطعام المحلي **60 ثانية**، فيحصل على وحدة
  من مصدر منتهٍ ثم يأكلها، دون شفاء أو طاقة مستنبطة.
- عند `t=191` تُحفظ لقطة SQLite ويُغلق العالم ويُفتح
  في جلسة جديدة، ثم يُرفض تكرار الأكل وإعادة أمر بتسلسل
  مراجعة قديم، وتُستأنف الحياة فقط بعد `wait 10`.
- تُقارن `WorldState` المعاد تشغيلها مع اللقطة،
  وتُثبت معادلات حفظ الموارد، وبقاء الشخصيات السبع.
  المحرك لا يدّعي أن شخصًا «نجا» لأيام أو أن اللعبة مكتملة.

## تشغيل فعلي

من مجلد `simulation`:

```powershell
$env:PYTHONPATH = "src"
python scenarios/test_village/play_integrated_journey.py
```

هذه الرحلة موجّهة تلقائيًا لتجربة التكامل؛ للعب الحر:

```powershell
python scenarios/test_village/play_living_village.py
```

يطبع الاختبار سجل أماكن ومشاهدات اللاعب فقط مع
`PLAY19_JSON` للتحقق الآلي. القسم `test_audit_only` مخصص
للاختبارات الداخلية **ولا يجوز إعطاؤه للراوي بوصفه علم كارلوس**.

**حدود العمل:** لا تعديل `main` أو القصة الأصلية.
Schema 34 / Rules 46 بلا تغيير. التجربة تستخدم SQLite مؤقتًا
قابلًا للاستعادة داخل اختبارات P0 فقط، لا حفظًا إنتاجيًا معتمدًا.
المراجعة المستقلة ومتطلبات P0 وPLAY-14g و03-A7c ما زالت مفتوحة.
