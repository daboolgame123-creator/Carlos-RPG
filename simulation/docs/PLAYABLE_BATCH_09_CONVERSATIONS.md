# PLAY-09 — سجل الحوارات الفعلية مع الشخصيات

هذا سجل تجريبي **محلي ومعزول عن القصة الأصلية**.

عند تشغيل القرية المؤقتة أو القابلة للاستئناف يمكن كتابة:

```text
talk basim greeting Hello
talk salma request_help Help
conversations
handoff
```

يعرض الأمر `conversations` آخر 20 **تفاعلًا وصل إلى شخصية واستجابت له**.
المدخل الواحد: معرّف الشخصية التي تحدث معها كارلوس، نوع الكلام، النص
الذي **كتبه اللاعب نفسه**، وتصنيف **رد الفعل المسجل** (مثل acknowledged أو
considered)، والزمن المنطقي. هذا **ليس** نص جواب منطوق من الشخصية ولا دليلًا
على دوافعها أو قناعاتها الداخلية.

يوصل `handoff` آخر خمس محادثات فقط داخل `player_conversations`، حتى يمكن
للراوي استئناف الحوار دون اختلاق ذكريات جديدة. تظل الذاكرة القديمة
`player_memory` مقتصرة على مشاهد النظر والقول المنقول حسب قواعدها.

## ضمانات السلوك

- السجل مبني على رسائل `SocialMessageSent` الخاصة بكارلوس بعد التحقق من
  وجود `received` في الحالة المعتمدة، وبترتيب تسجيل الحدث وليس بالحدس.
- لا يدخل حديث شخص آخر، أو تواصل لم يصل، أو محاولة رُفضت لغياب الشخصية.
- لا يكشف أرقام الثقة أو المعرفة الداخلية أو أهداف الشخصيات أو محادثاتها.
- السفر لا يمحو المحادثات القديمة ولا يمنح القدرة على الحديث عن بعد.
- الاستعلام لا يغيّر الزمن أو موارد العالم أو الأحداث أو ملفات الحفظ.
- لا زيادة في Schema 33 / Rules 43؛ لا API لشخص مجهول، ولا اختلاق حوار NPC.
- `03-A7c` و`03-A` مفتوحتان، والإنتاج P0 غير معتمد والمراجعة الخارجية مؤجلة.
  لا يتغير `main` أو نص القصة الأصلية.

## شروط إغلاق الدفعة

اختبارات متعدد الشخصيات (باسم وسلمى وعادل ونورا وهدى وغيرهم)،
المعلومات والخصوصية والحوار المكرر والتلاعب بسجل الأحداث والسفر،
وإعادة تشغيل SQLite والواجهتين؛ مصفوفة Python 3.10 و3.13 على
نفس SHA النهائي، وإصلاح أي فشل قبل إعلان الإغلاق.
