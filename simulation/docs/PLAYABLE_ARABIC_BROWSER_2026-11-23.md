# PLAYABLE WEB-01 — كارلوس في واجهة متصفح عربية (23 نوفمبر 2026)

**الهدف:** تجاوز مشكلة اتجاه العربية (RTL/BiDi) في Windows Terminal دون إعادة بناء المحرك أو تغيير اقتصاد القرية. هذه **واجهة حقيقية محلية تجريبية**، وليست لعبة مكتملة أو حفظًا إنتاجيًا.

## التشغيل من PowerShell على جهازك

داخل مشروع `Carlos-RPG-AR` بعد سحب فرع `feature/carlos-arabic-browser-local-play-20261123`:

```powershell
cd C:\Users\dell\Carlos-RPG-AR\simulation
$env:PYTHONPATH = "src"
python scenarios/test_village/play_village_browser.py
```

يفتح متصفحك تلقائيًا على عنوان محلي مثل `http://127.0.0.1:xxxxx/`. إذا لم يُفتح المتصفح، انسخ العنوان الإنجليزي المطبوع بعد `Carlos browser:` والصقه يدويًا في شريط العنوان.

**يُرجى إبقاء نافذة PowerShell مفتوحة أثناء اللعب.** عند الانتهاء اضغط `Ctrl+C` فيها؛ تُحذف قاعدة SQLite التجريبية، ولا يُمسّ `main` أو قصة كارلوس الأصلية.

## التفاعل

- صفحة ذات اتجاه يمين ← يسار تعرض **المشهد الفعلي** و**ممتلكات كارلوس فقط**، مع أزرار للمشهد والملاحظة والحالة والمخزون والعروض والمساعدة.
- أدخل أوامر واضحة في الحقل: `مشهد`، `اذهب home-market`، `انتظر 90`، `تحدث salma تحية مرحبا`، `العروض`، `اشتر <offer-id> 1 2`، `كل` و`تسليم`.
- الرحلة تستغرق وقتًا حقيقيًا داخل المحاكاة؛ لا انتقال فوري ولا أفعال كارلوس تلقائية. السكان يواصلون حياتهم وفق المحرك أثناء مرور الوقت.
- **لا حفظ دائم ولا توليد موارد.** حتى الأوامر المعروضة كأزرار تمر بالتحقق نفسه الموجود في `PlayerGateway`.

## حدود الأمان

الخادم يربط فقط `127.0.0.1`، ولا يفتح منفذًا على شبكة LAN أو الإنترنت. كل فعل `POST` يحتاج رمز جلسة لا يُخزّن في ملفات دائمة، مع تحقق من `Host` و`Origin`، وحد أعلى للطلب والنص، ومنع تكرار أوامر المستخدم غير المصرح بها عبر محرك اللعبة. لا تنفّذ طلبات `GET` أي تغيير في الزمن/الموارد، ولا تُحمّل الواجهة مكتبات JavaScript أو خطوطًا أو موارد من الإنترنت. كل نص ديناميكي يُحمى بتشفير HTML.

**هذه أداة اختبار محلية داخل جهازك فقط، وليست خدمة ويب جاهزة للنشر العام.** لا تعرّضها باستخدام port-forwarding أو شبكات عامة، ولا تستخدمها لحفظ القصة الأصلية.

## التحقق

- فحص RTL وHTML escaping وعدم تسرب البيانات أو تغيير الحفظ بمجرد عرض الصفحة.
- تجربة كاملة لأمر `مشهد`، وسفر حقيقي 90 ثانية، ورفض شراء غير مخول.
- اختبار subprocess حقيقي لخادم loopback (داخل Python آخر) وإثبات رفض محاولات Host/Origin/CSRF المخالفة على Windows وLinux.
- انحدار المحرك الشامل وفحوص الملف على SHA النهائي قبل إغلاق المهمة.
