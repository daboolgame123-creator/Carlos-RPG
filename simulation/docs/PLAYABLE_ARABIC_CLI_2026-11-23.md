بدل فتح إصلاح اقتصادي جديد، أضفنا طبقة عربية فوق **محرك PLAY-31 الحقيقي**: كارلوس يتحكم بأفعاله بنفسه، وسبع شخصيات مستقلة تواصل أعمالها أثناء مرور الزمن. لا تصنع الواجهة خبزًا أو مالًا ولا تتجاوز شرط الحضور/الطريق أو صلاحية اللاعب.

## التشغيل على Windows PowerShell

```powershell
git clone --single-branch --branch feature/playable-arabic-cli-20261123 https://github.com/daboolgame123-creator/Carlos-RPG.git Carlos-RPG-AR
cd Carlos-RPG-AR\simulation
$env:PYTHONPATH = "src"
python scenarios/test_village/play_village_ar.py
```

يلزم Python 3.10 أو أحدث فقط، دون API أو نموذج لغوي أو اتصال بالإنترنت عند التشغيل.

## معالجة عرض العربية على Windows PowerShell

بعد تشغيل اللعبة يمكن إدخال `مشهد` أو `المشهد`؛ كلاهما يعرض المشهد نفسه. تُحاول واجهة Windows تلقائيًا ضبط صفحة ترميز وحدة التحكم إلى UTF-8 دون تغيير ملفات الحفظ أو المحرك.

إذا ظلت العربية رموزًا غريبة في PowerShell التقليدي، أوقف اللعبة بـ `Ctrl+C` وشغّل من مجلد `simulation`:

```powershell
chcp 65001
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONPATH = "src"
python -X utf8 scenarios/test_village/play_village_ar.py
```

إذا استمرت الحروف غير متصلة أو مشوهة رغم نجاح الترميز، جرّب **Windows Terminal** بخط عربي مناسب؛ بعض نسخ وحدة التحكم القديمة لا تدعم وصل الحروف العربية جيدًا.

## تجربة حقيقية

```text
المشهد
الحالة
المخزون
اذهب home-market
انتظر 90
المشهد
العروض
تحدث salma تحية مرحبا
الذاكرة
تسليم
خروج
```

- `المشهد` يقرأ ما يمكن لكارلوس معرفته في مكانه **دون تقدم الوقت**. `انظر` يسجل مشاهدة فعلية.
- `اذهب home-market` يبدأ الطريق الحقيقي ولا ينقل كارلوس فورًا؛ `انتظر 90` يسمح بمرور زمن المحرك ونشاط الشخصيات.
- `العروض` لا يُظهر إلا عروض السوق المحلية المتاحة؛ `اشتر <offer-id> 1 2` يحتاج عرضًا صحيحًا ونحاسًا حقيقيًا.
- `كل` لا ينجح دون طعام مملوك، `ابحث` يحتاج موردًا متاحًا ومكانًا مناسبًا.
- `تحدث salma تحية مرحبا` يحتاج حضور سلمى الحقيقي؛ قد يرفض الأمر إن كانت بعيدة.
- `تسليم` يعرض JSON المتوافق مع `player_handoff` الأصلي **بدون كشف مخزون NPCs غير المرئي**.
- قائمة `مساعدة` كاملة؛ يمكن أيضًا استعمال الأوامر الإنجليزية السابقة. المعرّفات (مثل `home-market`, `salma`) تبقى ثابتة كي لا تتغير صلاحيات المحرك.

## حدود الإصدار

هذه واجهة **نصية عربية فقط**، وليست رسوم Isometric؛ إعداد واجهة مرئية يأتي لاحقًا ولا ينبغي الادعاء بتنفيذه هنا. قاعدة SQLite مؤقتة تُحذف بانتهاء الجلسة؛ لا تعتمد عليها كحفظ دائم. هذا عالم اختبار قابل للعب، وليس قصة كارلوس الأصلية. لم تُغيَّر قواعد الجوع أو الموت أو الاقتصاد، ولا ملفات قصة `main` أو بيانات مستخدم حقيقية.
