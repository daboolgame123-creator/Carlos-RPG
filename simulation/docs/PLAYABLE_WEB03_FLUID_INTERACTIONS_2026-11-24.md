# كارلوس — WEB-03: تجارة ومحادثات أسلس (24 نوفمبر 2026)

**هذه تجربة محلية قابلة للعب، وليست تعديلًا على المحرك الاقتصادي أو ملفات قصة كارلوس الأصلية.**

## ما تم تحسينه

- **الشراء دفعة واحدة:** بدل الضغط المتكرر لشراء رغيف واحد، اختر كمية من 1 إلى الحد الأدنى بين العرض المتاح وميزانية كارلوس الفعلية؛ يظهر السعر الإجمالي تلقائيًا. يُنفذ شراء الكمية كلها عبر **أمر شراء واحد** في `PlayerGateway.buy`، مع تحقق المحرك من ملكية الطعام، الكمية، العرض، السعر والنحاس عند التنفيذ. لا تُنشأ مواد أو نقود جديدة.
- **دون إعادة تحميل:** في المتصفحات الحديثة تُرسل الأزرار عبر `fetch` محليًا وتُحدَّث لوحة اللعبة داخل الصفحة نفسها، مع منع النقر المزدوج أثناء انتظار النتيجة. ولا يحتاج تشغيل اللعبة إلى مكتبات Python جديدة أو اتصال بالإنترنت. إذا عُطّل JavaScript، تبقى النماذج الأصلية `POST → 303 → GET` صالحة للاستخدام.
- **محادثات مفهومة:** يعرض قسم محادثات كارلوس **الكلام الذي أرسله اللاعب بالفعل** ورد الفعل السلوكي الذي سجله المحرك، مثل «استقبل التحية» أو «رفض الطلب». هذا ليس نصًا مؤلفًا على لسان NPC، ولم نضف ذكاءً محادثيًا أو أقوالًا وهمية.
- **الأمان:** بقاء `Host` و`Origin` ورمز CSRF، وعدم كشف مخزون NPCs أو الأماكن البعيدة. لا يسمح السيرفر إلا بـ`127.0.0.1`؛ `GET` لصفحة اللعبة أو `/ui.js` لا يغيّر العالم.
- **حدود WEB-03:** الجوع والتعب لدى كارلوس لم يُنفّذا داخل المحرك بعد؛ أشرطة HP/ST الحقيقية مستمرة مع وسم عدم تطبيق الجوع والتعب بدل أرقام مزيفة. لا رسوم Isometric ولا حفظ دائم بعد.

## الاختبار على جهاز Windows دون المساس بتعديلاتك القديمة

بعد إيقاف خادم اللعبة بـ`Ctrl+C`، نفّذ في PowerShell:

```powershell
cd C:\Users\dell\Carlos-RPG-AR
git fetch origin feature/carlos-web03-fluid-trading-dialogue-20261124:refs/remotes/origin/feature/carlos-web03-fluid-trading-dialogue-20261124
git worktree add --detach ..\Carlos-RPG-WEB03 origin/feature/carlos-web03-fluid-trading-dialogue-20261124
cd ..\Carlos-RPG-WEB03\simulation
$env:PYTHONPATH = "src"
python scenarios/test_village/play_village_browser.py
```

سيُفتح المتصفح تلقائيًا عند عنوان محلي عشوائي. اذهب إلى السوق، ثم انتظر حتى يظهر عرض حقيقي من البائع، وحدد الكمية المرغوبة دون تجاوز المخزون والسعر، وتحدث إلى شخصية حاضرة لعرض رد فعلها. قد يكون مخزون البائع في هذه التجربة **أقل من أربعة**؛ لا نخترع وحدات إضافية لتجربة شراء أكبر.

**تحديث worktree لاحقًا:** إذا كان المجلد الجديد خاليًا من التعديلات المحلية، اجلب رأس الفرع بالطريقة أعلاه ثم `git merge --ff-only origin/feature/carlos-web03-fluid-trading-dialogue-20261124`.
