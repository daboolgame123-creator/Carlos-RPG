# PLAY-01 — تجربة لعب مؤقتة + تسليم معلومات اللاعب إلى ChatGPT

**الهدف:** تشغيل كارلوس محليًا ضمن عالم اختبار صغير، ثم نقل ما يعرفه **كارلوس نفسه** إلى نموذج السرد، دون كشف سجلات NPC السرية أو تغيير العالم بمجرد العرض. هذه ليست القصة الأصلية وليست حفظًا إنتاجيًا معتمدًا؛ بوابة P0 لا تزال مفتوحة.

## تشغيل مؤقت وسريع (بدون حفظ)

من داخل مجلد `simulation` في PowerShell:

```powershell
$env:PYTHONPATH = "src"
python scenarios/test_village/play_local.py
```

الأوامر:

- `scene` — مشهد حالي للموضع والشخصيات القريبة والطرق **دون حدث جديد**.
- `look` — كارلوس يلاحظ موقعه عن قصد؛ تُسجل مشاهدة حقيقية في ذاكرته.
- `status` — حالة RPG الخاصة بكارلوس وحده.
- `remember` — ذكريات مشاهداته وأقواله المسموعة، مع تمييز الإشاعة غير المؤكدة.
- `handoff` — JSON للنسخ إلى ChatGPT: المشهد، حالة كارلوس، ذكريات كارلوس فقط؛ **دون تغيير الزمن أو الحفظ**.
- `move square-woods` ثم `wait 50` — رحلة تستغرق وقتًا؛ لا انتقال فوري.
- `talk basim greeting Hello` — فعل حوار صريح، يستجيب باسم وفق المحرك.
- `help`، `quit`.

لا تخلط `scene` (قراءة حالية) و`look` (حدث مشاهدة حقيقي). نتيجة `handoff` نسخة عرض لا تُنشئ أحداثًا ولا تعطي ChatGPT الحق بتغيير حقيقة العالم.

## تجربة قابلة للاستئناف — disposable فقط

يلزم إنشاء مجلد `test-backups` **مسبقًا**؛ الملف `test-carlos.sqlite` يجب ألا يكون موجودًا عند `--new`.

```powershell
$env:PYTHONPATH = "src"
New-Item -ItemType Directory -Force -Path test-backups
$sha = git rev-parse HEAD
python scenarios/test_village/play_resumable_demo.py --db test-carlos.sqlite --backups test-backups --new --code-commit $sha --disposable-test
```

للعودة إلى العالم نفسه (مع استخدام SHA النسخة التي أُنشئت بها النسخ الاحتياطية):

```powershell
python scenarios/test_village/play_resumable_demo.py --db test-carlos.sqlite --backups test-backups --resume --code-commit $sha --disposable-test
```

`scene` و`handoff` **قراءة فقط**، فلا يضيفان checkpoint؛ أما الأفعال التي تغيّر حالة العالم فتُتحقق وتُؤخذ لها نقطة حفظ مؤقتة. لا تعتمد على هذه التجربة كحفظ أساسي للقصة قبل اختبار الاستعادة المستقل على جهازك.

## نموذج التعاون مع السرد

انسخ JSON الناتج من `handoff` والصقه في محادثة ChatGPT مع الطلب:
«هذه حالة كارلوس المسموح بعرضها. صف المشهد وحوار NPC ضمن هذه المعلومات فقط؛ لا تخترع حدثًا معتمدًا ولا تغيّر إحصائيات أو موارد، ولا تحرك كارلوس نيابة عني».

**حدود المعرفة:** هوية الشخص الحاضر لا تكشف إصابته أو رأيه أو مخزونه. قد تتغير الأحوال بعد الرؤية، ولا يثبت الخبر السابق بقاءه صحيحًا. المخرجات لا تتضمن `WorldState`، سجلات الإصابات، معتقدات باقي الشخصيات أو الحركات البعيدة.

## بوابة التحقق

اختبارات PLAY-01 تشمل: المشهد قبل/بعد `look`، سفر كارلوس من البلدة إلى الغابة، حضور باسم ونورا وسارة حسب الموقع، رفض تسرب إصابة نورا المخفية، واتساق فتح SQLite مجددًا والملخص، مع اختبار CLI فعلي. لا تعتبر الدفعة معتمدة قبل نجاح CI على SHA النهائي في Python 3.10 و3.13.
