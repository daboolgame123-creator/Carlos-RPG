# PLAY-02 — قرية كارلوس الحية (تجريبية، بدون API)

**هذه تجربة جديدة قابلة للعب داخل محرك المحاكاة، وليست استيرادًا للقصة الأصلية.** تحتوي على كارلوس وسبع شخصيات مستقلة: باسم، سلمى، عادل، نورا، هدى، عمر، وليلى، موزعين على ثلاثة أماكن موصولة بطرق تستغرق وقتًا. لا يضيف هذا المستند وحوشًا أو قتالًا أو أحكامًا قضائية لم تُنفذ.

## التشغيل على Windows / PowerShell

من مجلد `simulation` داخل نسخة المستودع الحالية:

```powershell
$env:PYTHONPATH = "src"
python scenarios/test_village/play_living_village.py
```

أمثلة الأوامر:

```text
scene
look
talk basim greeting Hello
wait 180
scene
handoff
move square-bakery
wait 40
look
remember
quit
```

- `scene`: المشهد القريب الآن فقط؛ لا يحرّك الزمن أو يضيف حدثًا.
- `look`: يسجل ما شاهده كارلوس في هذا المكان **وقت المشاهدة**.
- `wait 180`: يحرك الزمن بمقدار 180 ثانية **محاكاة**، وتنطلق أفعال الشخصيات المستقلة وفق احتياجاتها وسماتها؛ يمكن أن تعمل أو تستريح أو تسافر وفق ما يسمح به المحرك. **لا يتحرك كارلوس تلقائيًا.**
- `move square-bakery`: سفر يختاره اللاعب بنفسه، وليس انتقالًا فوريًا؛ يلزم `wait 40` للوصول.
- `talk basim greeting Hello`: يرسل خطابًا حقيقيًا في المكان نفسه؛ يتلقى ردًا محسوبًا من المحرك، وليس حوارًا مخترعًا.
- `handoff`: JSON آمن للنسخ إلى ChatGPT يحوي مشهد كارلوس وحالته وذكرياته هو فقط. لا يحتوي على دفتر معلومات NPCs الخاص، ولا يغيّر أي حالة.
- `status` و`remember`: يعرضان الحالة الشخصية والذكريات وفق القيود الموثوقة.
- `quit`: تُحذف **قاعدة بيانات التجربة المؤقتة** عند الخروج. هذا مقصود، وليس عطلًا؛ اختبار الحفظ الطويل للإنتاج P0 ما يزال مفتوحًا.

## لماذا هذا مختلف عن تجربة اللاعب الأولى؟

المشهد السابق شمل شخصيتين مع اللاعب. في هذا المثال يوجد **سبع شخصيات مستقلة** موزعة في مواقع مختلفة، مع قواعد اختيار وأفعال ذات مدد محددة. عندما يختار المستخدم الانتظار، تتقدم أفعالهم وتُكتب كأحداث قابلة للتحقق وإعادة التشغيل في SQLite خلال الجلسة.

ليس كل فعل مرئيًا تلقائيًا؛ لا يسمح `handoff` للمستخدم بمعرفة دوافع الشخصيات أو الإصابات غير المشاهدة. ما يقع بعيدًا قد يحدث في المحاكاة، لكنه لا يُكشف لكارلوس دون قناة إدراك مشروعة.

## ضوابط الاختبار والاستمرار

- محلي فقط بلا HTTP أو API أو نموذج لغوي. يمكن لصق `handoff` هنا ليصوغ ChatGPT وصفًا من المعلومات المسموح بها، لا ليعدل حقيقة العالم.
- لا تخلط هذه النسخة مع قصة كارلوس الأصلية أو الحالة الدائمة.
- NPCs لا يحصلون على الموارد من عدم؛ أعداد `labor_units` و`investigation_attempts` مقاييس تجريبية مسجلة وليست مالًا أو خبزًا.
- تُختبر البنية، الحركة، الذاكرة الخاصة، رفض المحادثة عن بعد، ثبات المحاكاة، وإعادة تشغيل SQLite في `test_play_living_village_batch_02.py`؛ لا تُعلن الدفعة مغلقة قبل نجاح CI كامل على SHA النهائي في Python 3.10/3.13.
