## التدقيق الداخلي (ليس معرفة كارلوس)

- السبع شخصيات ما زالت موجودة في `WorldState` عند
  الحفظ والاستئناف؛ هذا ليس إثبات بقائها لسنوات.
- المحرك سجّل **12 فعلًا** للشخصيات،
  **7 سجلات سفر** و**7 تبادلات اجتماعية**
  خلال العالم التجريبي. هذه أعداد سجلات حقيقية.
- خرج من مخزون الأفران الأصلي 3 أرغفة إلى انتقالات
  معتمدة: واحد مع كارلوس، واحد عاد إلى سلمى،
  واحد أكله كارلوس؛ لا تضاعف.
- 10 قطع نحاس أصلية صارت 4 مع كارلوس و6
  مع سلمى؛ لا نقود مخلوقة.
- الطعام البري في الغابة نقص بوحدة واحدة بالضبط
  عندما أصبح كارلوس مالكًا لها؛ ثم أكلها.
- `store.verify()` تطابق مع `load()` ولقطة SQLite؛
  بعد الإغلاق لم يتحرك الزمن تلقائيًا،
  ورُفض تكرار أمر الأكل باستخدام ID ذاته
  ورُفض أمر بــrevision قديم.
- الحتمية مثبتة في نسختَي SQLite تجريبيتين منفصلتين.
  عروض `scene` و`handoff` لا تكتب ذاكرة أو تدفع الزمن.

## تجربة التشغيل على Windows

من داخل `simulation`:

```powershell
$env:PYTHONPATH = "src"
python scenarios/test_village/play_integrated_journey.py
```

للعب الحر بدل الرحلة الموجهة:

```powershell
python scenarios/test_village/play_living_village.py
```

يمكن تجربة تسلسل مشابه يدويًا:
`look` ثم `askfood basim square` ثم
`talk basim greeting Hello` ثم `buy salma-bread 3 2`
ثم `give salma bread 1` ثم `eat bread`،
وبعدها `wait 1` والتنقل إلى `square-bakery`
و`square-woods` مع الانتظار الواقعي عند كل طريق.
تغير تحركات NPC قد يغير مَن تقابله؛ لا تُفترض
محادثة مع شخصية غادرت المكان.

**حدود صريحة:** التجربة مؤقتة ومعزولة،
وليست عالَم قصة كارلوس الأصلي ولا حفظًا إنتاجيًا.
`Schema 34 / Rules 46` لم يتغيرا.
`PLAY-14g` و`03-A` و`03-A7c` و`P0`
والمراجعة الخارجية ما زالت مفتوحة.
